# Local backend verification

This is an evidence map, not a claim that every acceptance-plan bullet has a browser test. The acceptance specifications remain under `docs/plans/backend-acceptance/`.

## Recorded HTTP run (historical baseline)

On 2026-08-31, the pre-addition HTTP BDD baseline completed with **14 passing scenarios, zero retries**: 13 desktop Chromium scenarios and one Pixel 7 mobile scenario. The final-code rerun also passed 14/14 in 2.1 minutes, after the request-ID audit, portable-alias validation and failed-check regressions. It used the actual local Worker, D1 and R2, all three migrations, and the complete canonical bilingual seed. The frontend adapter was explicitly HTTP. No browser mock supplied successful responses, and no native WebMCP registration was fabricated.

This 14/14 result is retained as historical evidence from before the focused additions. It is not the current full-suite count.

## Current focused HTTP run

On 2026-08-31, the complete HTTP BDD suite passed **21/21 scenarios with zero retries** in 2.4 minutes: 19 desktop Chromium scenarios and two mobile scenarios. It exercised the actual local Worker, D1 and R2 with the frontend HTTP adapter, including the focused post-restart, offline retry, archive/delete, human fallback, pagination and cross-tab cases. No browser mock supplied a successful response and no native WebMCP registration was fabricated.

Run it with:

```sh
pnpm --filter @lorestra/e2e test:e2e:http
```

The harness owns port 4176 for Vite and 8795 for its Worker. Every scenario receives a private offline clone of a closed, seeded local store. Four synthetic opaque sessions are created through trusted local bindings, not through a public role-selection or reset endpoint. Trace, video and screenshot capture are disabled for this suite. The in-process Vite teardown avoids Windows shell-process-tree hangs; occupied ports fail instead of reusing or killing another server.

## Tooling and remaining acceptance work

```sh
pnpm test:tooling
```

The recorded tooling run completed with **8/8 passing tests** on 2026-08-31. It covers canonical Markdown parsing, safe paths and symlink rejection, migrations and immutable triggers, storage restart, repeated imports without overwriting a live revision, invalid-import rejection, backup/restore integrity, and the real local supervisor lifecycle (two start/stop cycles, one restart, full document-body/version preservation, cooperative Windows IPC shutdown and no retained operator lock). Portable export/import is not counted as full-history restoration. These checks are in `scripts/backend-seed.test.mjs`, `scripts/backend-runtime.test.mjs` and `scripts/backend-backup.test.mjs`.
