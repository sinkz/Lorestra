# Docs do Lorestra

Este é o ponto de entrada em português para o vault de conhecimento do Lorestra. Comece por [O que é o Lorestra?](o-que-e-lorestra.md) e siga para [Como usar o Lorestra](como-usar-lorestra.md) para navegar, buscar, propor e aprender com o histórico.

Agentes devem continuar em [Ferramentas WebMCP para agentes](ferramentas-webmcp-para-agentes.md) para descobrir o contrato nativo do navegador e seu limite de escrita baseado em propostas.

Os cookbooks são deliberadamente práticos:

- [Do incidente ao conhecimento reutilizável](cookbooks/incidente-para-conhecimento.md)
- [Registro de decisão](cookbooks/registro-de-decisao.md)
- [Handoff entre agentes](cookbooks/handoff-entre-agentes.md)
- [Preparar um lançamento](cookbooks/preparar-lancamento.md)

Estes documentos são Markdown no vault, não strings embutidas na aplicação. O frontmatter alimenta o menu, enquanto a policy de acesso decide qual projeção cada leitor pode ver.
