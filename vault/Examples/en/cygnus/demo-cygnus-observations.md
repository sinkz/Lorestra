# Cygnus: observation ledger

> Fictional demonstration. These examples are not records of real incidents, learners, or research results.

The demonstration ledger stores a session identifier, instrument label, declared unit, location description, timestamp, and raw value. It contains no real participant data, and an instrument label is not a claim that the device is calibrated.

Record “the displayed value changed” before concluding why it changed. A changed location, sampling interval, or unit can explain an apparent effect; attach those conditions before interpreting the comparison.

- Preserve missing values explicitly.
- Keep an annotation separate from a raw reading.
- Link each derived result to the source row and transformation.
