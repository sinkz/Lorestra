# Lyra: review routine

> Fictional demonstration. These examples are not records of real incidents, learners, or research results.

This example routine supports a short reading task with a text available to both participants. The teacher can adapt timing, accessibility supports, and response format to the class; the example does not prescribe a universal assessment method.

1. Read the prompt and mark one relevant passage.
2. Draft an interpretation independently.
3. Exchange drafts and ask where the passage supports the claim.
4. Suggest one precise change without rewriting the partner’s answer.
5. Revise and explain which evidence or reasoning changed.

Collect the explanations, not a ranking of pairs. Use recurring questions to plan the next lesson and record the learning in a proposal.
