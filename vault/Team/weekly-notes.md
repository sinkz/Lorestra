# Weekly working notes

This week's focus is to make the public read path credible without pretending that Cloudflare persistence exists. Engineering will verify the memory adapter and contract mapping. Product will check that every visible Docs item has an English and Portuguese counterpart. The team will review the proposal lifecycle for stale base versions.

## Open questions

- Which metadata belongs in the final transport contract?
- How should internal menu projections be scoped?
- What evidence is required before enabling authenticated writes?
- Which operation must be atomic when a proposal is merged?

These notes are coordination context, not a substitute for a decision record. Promote a conclusion into a focused proposal or durable document when it should survive the week.
